Conexión en Tiempo Real con Google Sheets

Integración mediante Web App de Google Apps Script

Formato esperado: https://script.google.com/macros/s/.../exec

¿Cómo funciona esta conexión?

  • El dashboard realiza una petición GET a tu Web App de Apps Script y lee directamente la hoja Dataset_Maestro de tu Google Sheets.
  • La URL se guarda localmente en tu navegador (localStorage) para reconectarse automáticamente al volver a abrir el archivo.
  • Activá el selector Auto-act. en la barra superior para sincronizar nuevos registros en vivo cada 15s, 30s, 60s o 5 min.
